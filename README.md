# 🎵 Spotify Web Clone

A **Spotify-inspired Web Player UI Clone** built using **HTML5 and CSS3**. This project recreates the visual layout of a modern music streaming platform, including a sidebar, navigation bar, music cards, library section, and bottom music player.

The project was created as a **frontend practice project** to improve my skills in HTML, CSS, Flexbox, responsive layouts, and UI design.

## ✨ Features

* 🎵 Spotify-inspired dark UI
* 🏠 Home navigation section
* 🔍 Search navigation UI
* 📚 Your Library section
* ➕ Create Playlist UI
* 🎙️ Podcast section
* 🎧 Recently Played section
* 🔥 Trending section
* 💿 Album/music cards
* 🎵 Bottom music player interface
* ⏮️ Previous and next control icons
* ▶️ Play button UI
* 🔀 Shuffle and repeat controls
* 🎤 Microphone and playlist controls
* 🔊 Volume control
* 📊 Music progress bar
* 👤 Profile icon
* ⬅️ Navigation arrows
* 📱 Basic responsive layout
* 🎨 Spotify-style dark theme

> **Note:** The buttons, music controls, search, and navigation are currently UI elements only. No JavaScript or backend functionality has been added.

## 📱 Responsive Design

The project includes a basic responsive media query for smaller screen sizes.

```css
@media (max-width: 850px) {
    .hide {
        display: none;
    }

    .sidebar {
        width: 260px;
    }
}
```

This adjusts some elements when the screen width becomes smaller.
